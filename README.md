# Korvai

Curated, reusable skills for knowledge work — PRDs, briefs, reviews, and more.
Install once; the skills become slash commands in Claude Code and Cowork.

## Install

**Claude Code / Cowork — from the Directory:** search for **Korvai** and install.

**Claude Code — from the terminal:**

```bash
claude plugin marketplace add https://github.com/getkorvai/korvai-plugin
claude plugin install korvai@korvai
```

Then use `/korvai:<skill>` as a slash command.

## Skills

- `/korvai:blog-post-outline` — **Blog Post Outline**: Generate a structured blog post outline from a topic and target audience in seconds.
- `/korvai:bug-triage` — **Bug Triage**: Transform a raw bug report into a prioritized, reproducible triage summary with severity, steps, and owner recommendations.
- `/korvai:code-review-checklist` — **Code Review Checklist**: Review a pull request diff for correctness, security, and maintainability using a structured checklist.
- `/korvai:cold-email-drafting` — **Cold Email Drafting**: Draft a personalized cold outreach email from a prospect profile and offer in minutes.
- `/korvai:competitive-teardown` — **Competitive Teardown**: Analyze a competitor product and produce a structured teardown covering positioning, strengths, weaknesses, and strategic gaps.
- `/korvai:contract-review` — **Contract Review**: Review a contract for risky clauses, missing obligations, and renewal traps to surface legal and business risks fast.
- `/korvai:customer-interview-synthesis` — **Customer Interview Synthesis**: Transform raw customer interview notes into structured themes, standout quotes, and actionable product decisions.
- `/korvai:incident-postmortem` — **Incident Postmortem**: Draft a blameless postmortem from an incident timeline and impact summary in minutes.
- `/korvai:job-description-writer` — **Job Description Writer**: Turn a role title and requirements into a clear, inclusive, ready-to-post job description.
- `/korvai:meeting-notes-to-action-items` — **Meeting Notes to Action Items**: Convert messy meeting notes into a clean list of owners, action items, and deadlines.
- `/korvai:personal-finance-health-check` — **Personal Finance Health Check**: A repeatable intake-and-diagnosis SOP that gathers the financial context people usually leave out, then grades the resulting advice against life-cycle finance principles. Education, not regulated advice.
- `/korvai:prd-writer` — **PRD Writer**: Transform a rough feature idea into a structured, actionable Product Requirements Document ready for engineering and design.
- `/korvai:sales-call-follow-up` — **Sales Call Follow-up**: Turn a raw sales call transcript into a polished follow-up email and structured CRM notes in minutes.
- `/korvai:standup-summary` — **Standup Summary**: Summarize a team standup meeting into clear blockers, progress highlights, and next steps.
- `/korvai:user-story-splitter` — **User Story Splitter**: Break a large user story into small, independently shippable stories with clear acceptance criteria.
- `/korvai:weekly-status-report` — **Weekly Status Report**: Transform raw work logs into a polished, stakeholder-ready weekly status report in minutes.
